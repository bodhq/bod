\section*{Anotace}
Práce se zabývá návrhem modulárního školního informačního systému bod se
zaměřením na správu rozvrhu, učeben a výukových skupin. Zahrnuje návrh
uživatelského rozhraní, backendu a databáze. Dokument je pracovní osnovou; popis implementace,
výsledky testování a závěry budou doplňovány podle skutečného stavu projektu.

\section*{Klíčová slova}
školní informační systém, rozvrh, výukové skupiny, učebny, webová aplikace

\section*{Annotation}
The project concerns the design of bod, a modular school information system
focused on timetables, classrooms and teaching groups. It covers the design
of the user interface, backend and database. This document is a working outline;
implementation details, test results and conclusions will be added as the
project progresses.

\section*{Key words}
school information system, timetable, teaching groups, classrooms, web application

\tocchapter{Úvod}
Školní informační systém propojuje správu uživatelů, výukových skupin,
učeben a rozvrhu. Projekt bod vzniká jako týmová dlouhodobá maturitní práce.

systému a datový model podle přiložených zadání.
