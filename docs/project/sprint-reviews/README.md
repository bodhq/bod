# Sprint reviews

Na konci sprintu vytvoř `sprint-N.md` podle šablony níže. Záznam uzavírají
oba členové týmu. U výstupů uváděj issue nebo PR; společnou práci v týmovém
součtu započítej jednou. Rozliš dokončenou a rozpracovanou práci, další
úkoly opatři vlastníkem. Pozdější opravu záznamu doplň datem.
